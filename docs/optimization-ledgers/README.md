## Reading the archive

- The journals preserve successful, rejected, inconclusive and superseded experiments. Read the dated retention decisions and pinned source revisions before reusing a result. This archive makes no new performance or correctness claims.
- Original project-relative paths, exact duplicate aliases, SHA-256 hashes, categories and copy transformations are recorded in [manifest.json](manifest.json). Source workspaces were not changed.
- Narrative and measurements are copied as written. Copy transformations are limited to line-ending/tab/trailing-whitespace normalization and explicitly recorded omissions of private repository references or operational details. Different historical versions are retained; only byte-identical source documents are deduplicated.
- Links and commands inside historical documents retain their original context. Some point to local checkouts, raw logs, plots, deleted experiments, GPU storage or private artifacts that are not bundled. The generated indexes and manifest provide navigation for the documents that are included.
- The search covered the local project workspaces and bounded ledger-name searches in relevant Git history. Vendored/source-clone documentation, generated PR-body copies, raw benchmark datasets, binaries, profiler traces, caches and unrelated training/deployment records are outside this text archive. See [coverage.md](coverage.md) for the search boundaries.
