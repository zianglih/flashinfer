# Empty-work native boundary on c1ac

No new prototype is justified by this bounded check. Current source and loaded control image are the c1ac/482b one-CTA CLC FC1 in `experiments/clc-info-vector/qualification/evidence/nvfp4-clc-1cta-control/codegen/` (cubin `6da029160136e9c14203875538579f85be5c39333ea642cce026403069c22809`). This is an actual compiled path, not evidence that every allocated padded ticket physically executed it.

The terminal metadata is tested before useful per-tile work: relay checks tile at0xf20/0xf30, MMA at0x1190/0x11a0, weight at0x19c0/0x19d0, epilogue at0x2440/0x2450, gather at0x3b20/0x3b30. Those branches skip operand copy/MMA/epilogue bodies. Gather has lane-coordinate arithmetic at0x3a00–0x3b10 before its first tile check, but this is invariant initialization once per physical CTA; the next-item path at0x40d0 onward does not repeat it. It is not repeated per-empty-ticket payload work and has no established profile cost warranting another predicate/control boundary.

Real startup work precedes the device route-count load: native barrier initialization0x140–0x680, TMEM allocation0x770/0x7e0 and all-thread retrieval barrier0x880 precede route-count LDG0x9b0. Source `moe_swap_ab_kernel.py:2675–2781` binds this to pipeline initialization, cluster/TMEM publication and PDL progress. Skipping it for an initially padded CTA requires a new converged early-exit/progress path; it is not deletion of an unconditional per-tile calculation. The CLC scheduler filters routed work before worker publication, while continuing cancellation for padding.

This reaches the existing boundary in `audits/clc-padded-retirement.md` and old `scripts/clc_elected_owner_20261026/padded-ticket-early-stop-review.md`: allocated padding is not measured physical launches, and early retirement can replace cheap cancellation with later physical startup. No actual current profile isolates avoidable padded-startup latency. The role-scoped TMEM startup/retrieval experiments are also already closed in `experiments/CLOSED_LEADS.md`. No source, timer, test or GPU run was added for this follow-up.
