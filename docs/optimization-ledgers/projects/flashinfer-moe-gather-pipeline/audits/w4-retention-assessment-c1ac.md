This is a recommendation only, under the current preference for measured benefit and minimal interface cost. No source edit, revert, new run, commit or publication is performed. Historical decisions and all negative rows remain intact. The four effects are independently paired against their own controls; their percentages must not be added or multiplied.

It does not claim the cutoff is incorrect, that a−0.9% loss has a clock-independent stable magnitude, or that removing it would numerically recover the cumulative deficit. No combined revised-source performance claim is available without new evidence; the user has paused that work.
