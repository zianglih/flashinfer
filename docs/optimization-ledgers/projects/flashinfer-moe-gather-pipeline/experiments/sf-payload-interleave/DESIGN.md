# Interleave existing SF copies and Gather4 issues

Base retained2b8; source-only prototype in `flashinfer-sf-payload-interleave-review`, branch `codex/sf-payload-interleave`. One unstaged swap kernel; no GPU compilation/qualification or timing yet. Main source remains clean.

The old loop issues every SF word, attaches SF completion, then issues every Gather4 task. The candidate flattens the existing row-block×SF-word order and uses one constexpr loop over the larger of SF slots and Gather4 task groups. Each step issues the next existing SF copy, attaches completion if this is the last SF slot, then issues the next existing Gather4 task group. Compile-time guards elide exhausted domains. No runtime cursor, new predicate, helper, buffer, tactic or ownership policy is added.

The expected payload bytes are announced before this loop. Every SF destination/source/zero-fill mask and every Gather4 coordinate/task owner is unchanged; each domain preserves its own original issue order. All SF copies precede their single original per-thread completion arrival. Earlier payload completion cannot publish the stage early: the same local barrier also needs all SF arrivals and all announced TMA bytes. Empty-stage waits, relay fence, two-CTA publication, MMA waits, pipeline advance, metadata and PDL stay unchanged.

History: bounded searches of the old `fc1-gather-20261028` ledger/source notes and `scripts/` found no matching slot-by-slot trial. The [whole-payload-before-SF experiment](../../../flashinfer-w4a4-split-dynamic-n/fc1-gather-20261028/full-20261029/payload-first/RESULTS.md) is closed:36 affected cells−0.178%, stable N3UEP4K W4A4−2.017%. That trial moved the entire payload burst first; this candidate retains SF-first at each step and the immediate final-SF completion point. The rejected SF lane-coalescing/route-sharing experiments changed ownership; this one does not.

The current TP profile identifies SF issue/completion MIO pressure and a later TMA burst. Alternation may expose independent issue sooner, but source order is not proof of native order or performance. First native qualification must check that interleaving survives lowering, no new local memory/control work appears, register/occupancy costs remain acceptable, and FC2 stays unchanged. A compiler-equivalent or costly result is sufficient to close it; no rescue policy is proposed.

SF body, TMA body (index rename only), and completion body are identical. Sixty admitted combinations of route N, CTA group, scale vector/operand kind and K steps preserve per-domain tuples and exactly one arrival after the last SF word.
