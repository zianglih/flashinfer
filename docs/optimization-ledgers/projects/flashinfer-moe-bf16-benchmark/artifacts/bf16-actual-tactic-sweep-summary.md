# Actual-input TRTLLM BF16 tactic sweep

Source: `2079fa00c4a2a0fb2e95bb284978a703653a4830`; isolated B300 GPU 1. CUDA graph+CUPTI+cold L2; 10 warmup and 100 timed iterations per tactic. The original benchmark source and all kernels were unchanged by the diagnostic. Root Nsight profiling was stopped during this sweep.

- All 352 native valid tactic pairs at 32 tokens and all 8 at 4096 tokens were measured once on the exact benchmark input closure, plus the native `-1` default.
- The best observed 32-token candidate was only about 1% faster than the native tuned selection. This single-sample search is not a precise 1% improvement claim; it rules out a missing native candidate that could approach the roughly 2.4x faster W4A16 result.
- At 4096 tokens the native tuned selection was also the best actual-input candidate.
- Native autotuning again ran 2,852 successful profiles with no failures; all 10 measured warmup/capture dispatches hit the retained cache outside tuning mode.

## Reproduce

```bash
cd /workspace/flashinfer-moe-bf16-benchmark/flashinfer
CUDA_VISIBLE_DEVICES=1 FLASHINFER_DISABLE_VERSION_CHECK=1 MAX_JOBS=8 \
python3 ../audit_bf16_autotuning.py \
  --repo /workspace/flashinfer-moe-bf16-benchmark/flashinfer \
  --output /workspace/flashinfer-moe-bf16-benchmark/artifacts/bf16-actual-tactic-sweep.json \
  --exhaustive --candidate-repeats 1 --capture-routing \
  --num-tokens 32,4096 --ep 8 --tp 1 --backends trtllm-bf16 \
  --include-activation-quant --use-per-token-activation --warmup 10 --iters 100
```

Replay tensors were collected outside timing through the same native runner, with `routing_replay_out` enabled only for this diagnostic call. Counts are native selected expert IDs, not an approximate host reference. The synthetic routing sample is the first candidate input at the corresponding native tuning bucket; actual is the benchmark input closure.

| 4096 | actual_benchmark | 3715 | 32 | 147 | 2818572288 |
| 4096 | native_synthetic | 1938 | 30 | 220 | 2642411520 |

The native tuner creates uniform random routing logits; the benchmark creates standard normal logits, with the same retained routing bias. On the 32-token native tuning probe only 11 local experts are active, versus 21 for the benchmark. This explains why a much shorter synthetic native tuning time does not imply that the benchmark accidentally timed extra work. The actual-input exhaustive candidate measurements above address this distribution mismatch for these two shapes.
