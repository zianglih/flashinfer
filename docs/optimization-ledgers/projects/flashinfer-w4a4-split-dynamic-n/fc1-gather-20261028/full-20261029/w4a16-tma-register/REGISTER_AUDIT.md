# W4A16 gather register redistribution

The lane-distributed route metadata source passed all 40 selected existing exact cases at the initial 144/80/96/96/64 role allocation. This keeps the input gather as the last warpgroup. The metadata source is frozen remotely as `flashinfer-metadata64-control`, patch `9b79b2625e72da96abf23a0a7f46fb308881164249c9674b2aada0c6058838f5` against fb66a27e.

The candidate moves 32 registers per gather thread to the two decoder groups: **144 epilogue / 80 control / 112 decoder / 112 decoder / 32 gather**, still 96 initial registers and a 61,440-register CTA pool. FC2 remains unchanged. No tactic axis or model/topology branch is added. Candidate patch `4da512183ace6f2ba6704823ede152ed7b14354ed975c41dd839f05a23e031f9` against fb66a27e.

A linear scan from the gather SETMAX instruction to the end of SASS misleadingly reported R61/R62. The compiler places cold blocks belonging to other warp roles after the gather body. A conservative control-flow walk from the gather donation, following conditional branches both ways and stopping at exits, shows no reachable register or implicit vector endpoint above R31. It encountered no unresolved indirect branch, call, or reconvergence instruction. The audit includes 33 existing W4 test instances (N8/16/32/64/128/192, one/two-CTA and multicast, old/new weight layout, non-power-of-two top-k, SiTU/GeGLU/ReLU2) and all four full EP model codegen captures. All 37 compiled kernels reserve 96 initial registers and have zero local bytes / LDL / STL. Compile-only tests deliberately skip before launching the affected W4 kernel; those skips are codegen evidence, not correctness passes.

The source-paired performance screen compares only this redistribution against metadata64 with the same frozen native winners, routing, physical GPUs, 10 warmups and 100 cold-L2 CUDA graph CUPTI measurements in C-A-A-C order. Geometric ratios are sqrt(C1*C2/(A1*A2)). The prior native retune is a distinct tactic experiment and is recorded under `../w4a16-tma-gather/native-retune-screen.csv`.

Local register-review is based on 7106faf, while remote measurement clones are fb66a27e. The four edited source file contents were verified equal before deployment; the absolute patch hashes therefore differ with the parent checkout. `metadata64-local-source.json` records the local snapshot. Preserve the exact remote patch/source manifests when composing results.

The112-decoder redistribution was rejected after the full32-cell fixed-winner campaign: EP decode−0.30%, EP prefill−1.39%, TP decode−0.33%, TP prefill−0.65%. All40 existing exact tests passed, but neither timing nor instruction simplicity justified retaining it. The rejected local review clone was removed. Exact measured patches and source manifests remain in the local evidence directory; the separate176-epilogue experiment and metadata64 control are unaffected.
