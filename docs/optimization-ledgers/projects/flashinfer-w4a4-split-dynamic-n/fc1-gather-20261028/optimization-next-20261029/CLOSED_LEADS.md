Search this index first, then targeted artifact Markdown and saved patches for mechanism synonyms. Searching only `scripts/` or handoff notes misses experiments. Keep raw evidence in its original directory; this file is an index, not a replacement ledger.

- **Three channel tiles sharing B:** [`nb3_experiment`](../../scripts/nb3_experiment/README.md). Logical M768/N128 used three MMAs per K stage and a shallower three-stage operand ring; byte-exact but slower in the recorded NVFP4 prefill screen. Not a drop-in extension of the current half-TMEM overlapping-window contract. Do not reintroduce it merely to reduce gathered-B traffic.

- **Share payload/SF route decode:** [ownership audit](sf-payload-ownership-audit/AUDIT.md), [failed codegen](sf-payload-ownership/GATE_RESULTS.md), and subsequent `sf-payload-deferred-offsets`, `sf-payload-linear-guard*`. The same-warp permutation reduced mapping loads but increased instructions/R2UR and introduced N256 local storage. Read these before proposing coordinate reuse.
- **SF cp.async L2 priority:** [prior lowering failure and neutral wide screen](../../scripts/sf_priority_20261026/README.md). Four-byte cache-hinted cp.async produced an illegal-instruction launch in the full kernel despite a valid isolated encoding; several lowering variants reproduced the problem. No workaround was retained. Direct SF TMA is separately blocked by the sub-16-byte canonical layout permutation: [transport audit](sf-transport-audit/AUDIT.md).
- **SF producer full/tail K peeling; repeated channel-bound comparison:** [ce4 generated-code audit](sf-k-bound-audit-ce4/VERDICT.md). All374 SF copy sites across41 current FC1 captures reduce source validity to a row comparison or constant tail zero-fill; a historical56-stage native MXFP8 loop agrees. Keep the single source loop. Distinct from the rejected SF/payload route-ownership experiments; no new GPU run or timing claim.
- **Metadata-window B-stage cap; `(S+1)*K` physical capacity:** [publication/retirement audit](metadata-stage-cap-audit-ce4/VERDICT.md). W4 finite metadata proves a logical issuance bound only; pending asynchronous B-empty arrivals are not bounded by that proof, and accumulator-full is a different barrier. Do not shrink slots or add synchronization to force the cap. Swap ordinary scheduling has no metadata pipeline. Distinct from the old one-tile clamp; no source/GPU change.

- **W4 independent A/B stage balancing; raw-plus-decoded inventory:** [32-cell rejection](w4a16-independent-stages/RESULTS.md), [qualification](w4a16-independent-stages/QUALIFICATION.md), [source/storage proof](w4a16-independent-stages/DESIGN.md). A4/B4/D2→A2/B5/D2 passed39 exact/graph cases and reduced SMEM, but caused strong FC1 weight/dequant supply regressions (whole-screen−6.76%, prefill−11.38%; V41F4K−34%). Logical queue inventory was not an adequate latency model; shrinking raw-weight residency can starve the serial weight/dequant path even when matched inventory is unchanged. Do not narrow this rejected policy with shape/dtype/model gates. All32 rows, per-FC timings, stock-clock variation and5 unchangedN192 controls are retained.

- **W4 FC2 late TMA output acquire; deterministic GEMM2 store wait at buffer reuse:** [historical audit](w4-late-store-acquire-audit/HISTORY.md), original W4 ledger `w4a16_optimization_experiments.md:5607–5653`. The isolated non-descriptor FC2-only July24 trial already moved the same wait/reuse join before shared overwrite, passed six numerical cases, and was rejected as neutral: EP8/TP8 sweep +0.191%/−0.001%; isolated EP4K +0.037%. The October28 descriptor source03→04 experiment moved both gated and nongated waits and measured +0.365% over32 cells, but does not isolate FC1 or establish a gain for current non-descriptor W4. Do not repeat the closed FC2 mechanism; an FC1 proposal first needs new output-wait evidence. Distinct from the rejected transformed-weight acquire/decode pipeline experiment.
- **W4 scales before decoded-slot acquire; raw packedA/SF preload:** original W4 ledger `w4a16_optimization_experiments.md:4727–4752` rejects the SF-only GEMM2 variant after6 exact cases and a neutral adjacent dense gate (432.479 versus434.335µs). Saved K3 EP4K/8K iKET decoded-slot waits are25.2–25.5ns, median/p95=32ns, near marker resolution: [source-bound trace audit](w4-late-store-acquire-audit/prior-trace-audit.json). Whole raw+SF staging while retaining decode/store interleaving is a distinct hypothesis but needs a new measured wait signal; do not repeat SF-only movement or move the entire decoded tensor across the wait.

- **W4 current gated-FC1 output/decoded-slot wait diagnostic:** [b52 sampled iKET](w4-output-acquire-iket-b52/RESULTS.md) retains all20 raw launches for K3 EP4K and V41F TP4K. Final cold-graph output acquire means52/43ns (median32ns, max160ns), decoded-slot means30ns (median32ns). Eight actual NativeDump/loaded-function guards pass; source AST is unchanged after marker removal. No substantial wait bubble supports an FC1 late-acquire or raw-preload candidate now. The measured issuer scopes include marker/instruction overhead and exclude the following writer join; the3.3–6.2% epilogue-scope fraction is not removable latency or an E2E speedup estimate.

Original no-new-local-site failure, explicit41-case experimental resource exceptions, failed prelaunch runtime-image/static-shared guard assumptions, and all raw native/stress evidence are preserved. - **Swap warp-private shared FP32 transpose / 8704B scratch:** [24-cell rejection](shared-fp32-transpose-screen-r2/RESULTS.md), [qualification](shared-fp32-transpose-b52-r2/QUALIFICATION.md), [peer raw audit](shared-fp32-transpose-screen-r2/peer-raw-audit.json).
