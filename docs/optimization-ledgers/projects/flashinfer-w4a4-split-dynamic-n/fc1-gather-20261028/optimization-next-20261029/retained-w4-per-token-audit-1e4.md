# Retained W4A16 and shared quantizer complexity audit

Read-only audit through `1e4b127a0901282bda5faec70ef6d5a19c835943`. No new GPU work, source edits, retuning, or reinterpretation of historical repeats. Current user rule: neutral performance does not justify added kernel complexity. Near-neutral changes that remove state or branches are a separate category; correctness and explicitly requested diagnostics also have separate purposes.

## Recommendation

**Remove `3b8c1c9e`'s custom all-slot terminal-drain helper and restore the SDK operand tails.** This is the clear retained addition with explicitly neutral timing. It adds a private barrier-wait implementation and call-site contract, rather than merely deleting redundant state. The other post-five-WG W4 changes either simplify source, have useful measured gains, or implement the requested optional tracing. The two later per-token changes have measured gains and compact general policies; keep them.

This is a source/history recommendation, not a claim that the composed revert is already qualified. It does not recommend removing an algorithm based solely on one historical noisy regression.
