- TMEM ownership: N16/32/64 and M256/N128 use the existing accumulator-stage pipeline. M512/N128 and M256/N256 enable the pre-existing overlapping-accumulator path. The actual SF footprint defines a32-column-rounded protected interval, epilogue traversal reads that interval first, and its fenced release occurs once before reuse. SF32 warp-reduction scratch is confined to the four epilogue warps; dtype mixing does not change its lane ownership.
