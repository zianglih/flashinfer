# Independent multi-stage startup review

No correctness blocker found in frozen 853 + patch `9cea43321866c8b08fa5b2371c436f78cbc1e46e6117838cbd960741e134dc07`. All 83 local source pins match the frozen source and successful gate receipts. Only the common kernel differs from the one-stage candidate; host knobs/defaults and FC1 publication behavior remain identical.

- The startup depth is `min(actual num_stages, ceil_div(static reduction_size, tile_k))`. The wrapper declares reduction_size Constexpr and builds the weight layout from it; actual stages are selected before kernel compilation. Thus the prefetch count is a compile-time layout/capacity calculation. It neither reads a model threshold nor laps the ring before the dependency wait.
- The temporary startup producer advances over distinct initially empty slots. It acquires each slot and arms the unchanged full A/SFA/B/(TMA SFB) transaction count once. The ordinary producer intentionally starts at slot 0/initial phase, skips the primed A/SFA acquisitions for the first work tile, completes B/SFB after the wait, then advances normally. K beyond the primed prefix and all later persistent work tiles use the original acquisition path. Producer tail drains the ordinary state after all work.
- For small N, SFB remains on its separate cp.async barrier after the wait; for TMA-SFB geometries, its bytes complete the existing TMA barrier after the wait. The MMA consumer remains downstream of both readiness paths. All CTA threads still execute the dependency wait, including nonproducer warps and no-work CTAs. TMEM allocation/retrieval synchronization happens before role divergence.
- Compile-bound NVFP4 N16/K2304 PTX has four 45056-byte expect-tx operations at barrier offsets 0/8/16/24 before the wait at 322. Each is 32768 A + 4096 SFA + 8192 B. Exactly 8 weight 3D + 4 SFA 4D TMAs and the two allowed routing metadata loads precede the wait; there is no B/SFB payload read before it. SASS places all 12 early UTMALDG instructions before ACQBULK 0x1120; B begins after it.
- The first four unrolled regular K stages skip reacquisition when `tile == block` (PTX 382/514/612/710). The fifth stage takes its normal acquire at 822, after the wait and ring-consumer progress. PTX 887 advances persistent work by the grid stride; subsequent work does not satisfy the initial-tile predicate. The no-work and nonproducer branches join the same wait label.
