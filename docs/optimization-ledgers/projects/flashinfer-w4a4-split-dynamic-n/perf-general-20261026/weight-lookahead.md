# Weight-data L2 lookahead

Independent unstaged source: `../flashinfer-weight-lookahead-20261026`, based on clean0def. Only the common `load_weight_stage` helper changes. After issuing the current A/SFA copies, it submits TMA prefetch hints for A/SFA one existing operand-ring length ahead. The distance is the resource-derived `self.num_stages`; no new knob, dtype/geometry switch, buffer or synchronization operation is introduced. The hints never replace ordinary copies or barrier completion. A K-bound guard prevents requests outside the same expert/channel tile.

This is data prefetch into L2, distinct from the rejected tensor-map descriptor prefetch and the retained startup copies into shared memory. Startup PDL already calls this helper, so the same bounded lookahead can run during the existing dependency-overlap window. Weights and their scales have no dependency on preceding activation writes. The existing activation dependency wait stays in place.

The installed CuTe4.7.1 `cute.prefetch` implementation accepts the existing TMA copy atom and partitioned source tensor, constructing its executable form with dummy destination barrier/multicast arguments. The operation manages its own single-thread election. It has no cache-policy keyword, so this trial uses the native prefetch policy, while actual weight/SFA copies retain evict-first and activation payload retains evict-last. This policy boundary must be considered if the experiment is retained.

References: [CuTe prefetch](https://docs.nvidia.com/cutlass/latest/media/docs/pythonDSL/cute_dsl_api/cute.html), [PTX bulk tensor prefetch](https://docs.nvidia.com/cuda/parallel-thread-execution/index.html). Installed SDK inspection is captured by `inspect_prefetch_sdk.py`.

Rejected after the fixed V41 EP4 CAAC screen. All four narrow/wide NVFP4 and MXFP8 codegen/execution profiles passed. The nine affected timing points regress: NVFP4 speedups 0.9603/0.9778/0.9590, MXFP8 0.9683/0.9918/0.9615, and MXFP4x8 0.9070/0.9417/0.9431 at tokens32/128/4096. The public benchmark uses identical routes, fixed K8 tactics, 10warmups/100cold-L2 CUDA-graph CUPTI samples and includes initial NV quantization. All four source-paired arms completed and verified. No native AUTO/full-grid expansion or production changes are justified. See weight-lookahead-comparison.json and weight-lookahead-results/ for raw data. All native C++ artifacts stay on persistent cluster storage; changed CuTe source receives a private cache namespace.
