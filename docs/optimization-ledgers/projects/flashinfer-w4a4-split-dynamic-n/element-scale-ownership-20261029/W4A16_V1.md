Warp6 issues elements and retains the single full-barrier announcement for raw A+SFA. Warp7 independently waits on raw-slot reuse and issues SFA against that barrier. FC1's input gather remains in warps16–19; all active warps now consume tile metadata (the formerly idle warp7 adds32 consumers). FC2 still uses its existing regular-TMA B path.

FC2 warp6 has independent A and B producer cursors. A prefetch reads future entries of the existing tile-info ring without releasing them. B copies and releases each item once; the A cursor caches its current work item so a released item can be overwritten while its remaining K stages are issued. The tile-info cursor-distance bound prevents reading past retained slots. The lookahead uses raw-empty and metadata try-waits and stops at real backpressure. Only if A has not yet issued the current B stage may the elements warp block on raw-empty; all older B stages were already issued, so independent transforms/MMA can release that raw slot. No auxiliary shared or local metadata queue is added.

The first dependent B issue performs the original PDL wait and finalizer startup signal after ready weight stages have been prefetched. The zero-work case still performs that dependency wait/signal. SFA has no activation dependency in W4A16 and runs ahead independently. The original raw, transform, activation, accumulator and scheduler stage counts/lifetimes remain; there is one original A tail and B tail. The raw full barrier still announces exactly A+SFA once. No tactic, layout, output, inherited transform or dequantization helpers changed.

Static checks passed: scoped pre-commit (including mypy/ruff), Python compilation and `git diff --check`. GPU compilation, exactness, liveness and performance remain pending.

The benchmark agent was asked to prioritize K128 FC2 with many tiles under CLC and static scheduling (cross-tile metadata phase wrapping), one/two CTA, PDL off/on, zero-work/terminal handling, and both gated weight layouts. The new control state also requires register/spill inspection; unchanged80-register control-warpgroup allocation is deliberately the first measured baseline.
