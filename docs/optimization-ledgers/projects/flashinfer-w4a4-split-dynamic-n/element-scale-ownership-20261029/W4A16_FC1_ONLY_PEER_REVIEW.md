- **Single raw-full announcer preserved.** Warp 6 alone calls `a_load2trans_pipeline.producer_acquire/commit/tail`. The unchanged `PipelineTmaAsync` full barrier still expects one arrival and `a_copy_size + a_scale_copy_size` bytes. Warp 7 only waits for the matching raw-empty index/phase, then issues the original scale TMA with the same full barrier, destination and multicast mask. It does not announce the byte sum again. Transform consumers cannot release the raw slot until both TMA contributions complete and their reads finish. An independently faster scale warp is bounded by those same empty phases, including wraparound.
- **Independent cursors remain aligned.** Both FC1 producer roles initialize the same raw-ring state, reset only its K count per work tile, and advance once per K stage. They consume identical scheduler metadata in order. `make_contiguous_group_work_tile_info` copies its four fields into registers before the metadata release, so subsequent producer work does not retain a reference to an overwritten slot. Neither role introduces a dependent activation wait or lookahead cursor.
- **Metadata and terminal handling match the new active warp.** FC1 adds exactly 32 consumers: 640 total threads minus the 32 scheduler threads = 608. FC2 remains 512 minus 32 = 480. Each role reads/releases the initial metadata item and every successor, including the invalid terminal item, before testing the loop condition. This also covers an empty-work CTA. CLC and ordinary scheduler code is unchanged.
- **PDL ownership is preserved.** Gathered FC1's existing grid dependency wait remains before any routing access. Only role zero/warp 6 executes the original first-item signal and ancestor release, at the same point and even for an initial terminal item. Warp 7 neither adds a signal nor waits on activation readiness. The two-CTA addressing, multicast, transform and MMA ownership are unchanged.
- **FC2 specializes back to the retained source.** The regular B-producer source block is byte-identical. Independently replayed `validate_w4a16_fc1_only.py` assertions without rewriting its receipt; the entire FC2 kernel AST matches base after folding `gather_input=False` and the sole role-zero iteration. Also checked the whole module outside `kernel` is AST-identical, not merely the listed class methods. This is source equivalence, not a compiled-binary identity claim.
