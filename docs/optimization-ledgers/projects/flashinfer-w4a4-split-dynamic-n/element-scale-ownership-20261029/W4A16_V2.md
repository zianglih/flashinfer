The merged elements role exhausts currently ready A slots and metadata before its PDL wait. While blocked in that wait it cannot fill slots that become ready later, unlike an independently running weight-only warp. Blocking on optional future metadata could create a dependency cycle, so this is an explicit performance tradeoff for measurement rather than a reason to add another producer role or queue.
