# Generality audit and native screen

Source work is isolated in the shared `flashinfer-generality-review`; production remains clean. Remote `generality-r1` started from exact clean84f9 and is ready for one frozen patch. No GPU gate or timing starts before source freeze.

`run_gate.py` reuses the prior68 selector set, collecting concrete existing test IDs before execution. `probe_chain.py` uses the existing public benchmark setup and wrapper, with fixed legal geometry only for validation:16 configurations and96 changing-data/route replays per source, N16/32/64/128/256, M128/256/512, one/two CTA, NVFP4 tensor/token and both MX modes, SiTU, partial routes and zero-local work. PDL off/on must match bitwise, and clean84f9/candidate hashes must match. FC2 uses sm_count2 to cover later persistent tiles. This is not performance evidence or a claim of cross-backend exactness.

`launch_screen.py` reuses the native public benchmark observer. Default screen is tokens4,32,128,512,4096 on all3models, one GPU per model and sequential NV/MX families. Use `--tokens 1,2,4,8,16,32,64,128,256,512,4096,8192,16384` for final grids. Tokens1/2 are measured when requested and excluded from retention aggregates. NativeAUTO, DAoff, PDLon,10warm/100measured cold-L2 CUPTI CUDAgraph timing; initial activation quantization excluded. No historical original baseline reruns.

Omit backend selectors for native TRT comparison tables. For bounded causal kernel screens use `--nvfp4-backends cutedsl,cute-dsl-per-token --mxfp-backends cute-dsl-w4a8,cute-dsl-mxfp8`. The existing selector includes unaffected W4A16 as a control. Unsupported K3 TRT arms remain explicitly unavailable. Only post-timing observations are added: raw medians, existing routing identities/histograms, and savedAUTO choices. No timing helper or public API behavior is replaced.

The source receipt captures all CuTe files, public prep/API, trace reference and existing test files; dirty source requires its exact patch hash. Timing runs use private source-keyed compiler caches and freshAUTO. Runtime imports and systemnvcc are recorded separately.

The PDL gate can reuse the completed clean control via `--reuse-control` plus its exact result SHA256. It binds the original successful validation, GPU UUID and native environment, and copies the immutable control results into the new receipt. `evidence/generality-pdl-r1/control-reuse-proof.json` proves the input construction and entire replay loop are unchanged. The new observer only records compiled kernel attributes while forwarding all original compiler options. `--require-expanded-pdl` requires effective FC1 CLC one-CTA, FC2 two-CTA, and both per-token phases to prefetch, with every PDL-off specialization disabling prefetch. The quantizer source is explicitly pinned, bringing the standard source set to86files.
