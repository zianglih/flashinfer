# Per-token gated activation before a single transpose

Independent unstaged source `flashinfer-epilogue-20261026`, parent0def601d. Only Blackwell `utils.py` changes (+17/-9). The separate pipeline-prefetch candidate stays frozen and unchanged. No reference/test additions, public flags, model/dtype/tile thresholds, buffer changes, pipeline changes, or MegaMoE edits.

The gated per-token path formerly transposed both raw up and gate fragments into lane=token ownership, multiplied by the rounded expert/token scale, then activated. The replacement computes each lane's same `alpha * per_token_scale` (same guard, route lookup and FP32 association), shuffles these combined scales into native Ld16x64 fragment ownership, activates with the existing packed function, and transposes the result once. Uniform-alpha behavior also calls the same helper but compiles out scale shuffles. Non-gated Relu2 and FC2 paths retain their existing helper calls/semantics.

Raw register i of lane L holds token `2*i + (L//2)%2`, channel `8*(L%2) + L//4`. This follows CUTLASS `SM100_TMEM_LOAD_16dp64b16x` traits and matches current read-only MegaMoE `moe_nvfp4_swapab/epilogue_refactor.py:1693`. Every lane remains active at shuffle/TMEM atoms; invalid token lanes contribute alpha only and their outputs remain guarded. The change replaces one complete TMEM transpose with16SHFL instructions per warp, without changing the weight layout or holding accumulator ownership past the existing final transpose/read fence.

`prove_layout.py` transcribes all five involved CUTLASS copy-atom coordinate layouts, simulates the exact existing TMEM transpose sequence (including bottom-fragment scratch placement), and checks old double-transpose/activation against new native-activation/single-transpose expression trees. It passes512 native coordinates and16,896 operation-tree comparisons over all33partial-token counts. RouteN16/32/64/128/256, one/twoCTA groups and one/twochannel tiles reduce to translated instances of this same warp mapping. These are CPU layout/association proofs, not GPU numerical coverage.

All gated activation formulas remain unchanged: ordinary/capped SwiGLU, SiTU with optional linear clamp, and GeGLU-tanh use the identical componentwise arithmetic. Changing paired lanes from same-token channels to different tokens has no cross-component arithmetic. Output dtype and quantization are downstream of the unchanged result transpose. In-place NVFP4 standard quantization remains the0def donor port.
