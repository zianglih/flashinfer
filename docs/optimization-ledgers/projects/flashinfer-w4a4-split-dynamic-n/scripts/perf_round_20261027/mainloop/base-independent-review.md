# Multicast base gate: independent artifact review

Candidate `c9854f44` on `2995bfda` passes this bounded artifact review. `review_base_codegen.py` independently verifies all 381 collected hashes, all 87 control source blobs against Git, the candidate freeze, all 64 paired replay outputs/inputs/routes/tactics, and 32 core plus 10 PrepareRouted pairs. Every core retains its stage/storage/geometry/commit metadata and exact register/shared/stack/local-memory resource counts. No local-memory spill loads/stores appear.

- **Unaffected paths:** 23 of 24 cores have identical instruction encodings and scheduling control words. The remaining one-CTA per-token FC1/PDL-on core has the same 17-row descriptor-pair permutation encountered in the structural cleanup: UR18:19 and UR20:21 exchange allocation. All four registers are unconditionally defined before use, the mapping holds over all subsequent uses and loop backedges, no use follows `0x4470`, and earlier independent lifetimes are unchanged. Every address, opcode, instruction order, control word, and resource count is unchanged. This is explicitly an exception to strict encoding identity. All 10 PrepareRouted pairs are encoding-identical.
- **Changed paths:** all eight wide two-CTA cores emit `UTMALDG.3D.MULTICAST.2CTA` with destination mask 3. The PTX combines `cluster_ctarank | warp_id` and branches around the SFB issue group when nonzero. Thus CTA1 no longer issues the duplicate global request; both existing local destinations are filled. The per-destination transaction count remains unchanged. FC1/FC2 and PDL on/off are covered for NVFP4 and MXFP8 in this base gate; the extra gate covers wide per-token and MXFP4x8, static scheduling, short K and a channel tail.
- **Synchronization:** all steady-state barrier wait/arrival, UMMA commit, and PDL instruction-site counts agree. Expected transaction byte immediates agree in every core. In the representative wide NVFP4 smoke these are 155648 bytes for FC1 and 77824 for FC2. MXFP8 FC1 has one additional compiler-generated initialization fence per PDL variant: the old lowering shared one fence before initializing barriers at shared offsets `0x28` and `0x38`, while the new lowering fences each initializer. This is startup cost, not an added wait or new source synchronization rule.
- **Instruction cost:** the eight changed cores sum to +96 static instructions including NOP padding, or +77 excluding NOPs. NVFP4 changes are +5/+5/+6/+3 non-NOP instructions (FC1 off/on, FC2 off/on). MXFP8 changes are +35/+12/+7/+4. MXFP8 FC1/PDL-off also increases paired `MOV.SPILL`/`R2UR.FILL` from 51 to 60 sites; these are uniform-register transfers, not local-memory spills. No total instruction-reduction or latency claim is made. Timing is needed to assess the duplicate-TMA reduction against the owner/mask and compiler costs.
