# Remove redundant inactive SF source-row selection

Frozen `f7182d5c` candidate: one core file, +1/−4 lines; the only change passes `route_start + row` directly to the existing scale-layout offset. The copy predicate, destination addresses, zero filling, cp.async issue counts, pipeline phases and resource geometry are unchanged. No tuning axis or dtype/shape condition is added. Source remains unstaged in `flashinfer-sf-source-address-20261027`.

The existing `_copy_tile` predicated CuTe copy lowers to `cp.async.ca.shared.global [dst], [src], 4, src_size`, where `src_size` is zero on an invalid row/K block. Current f718 baseline SASS still has the redundant source selector (`composition-evidence/composition-smoke/candidate/config0-fc2-pdl0.sass`, address `0x0900`), preceding the masked LDGSTS sequence. The compiler has not already removed the source-level operation.

[PTX cp.async semantics](https://docs.nvidia.com/cuda/parallel-thread-execution/index.html#data-movement-and-conversion-instructions-cp-async) define src-size as bytes read and fill the remaining destination bytes with zeros. With size zero, no source bytes are read. Direct row arithmetic still produces a four-byte-aligned address. A lane beyond the last physical padded SF allocation can compute an out-of-allocation pointer, but its row predicate is false and the pointer is not dereferenced. Live rows compute exactly the old address. Partial K retains its unchanged combined row/K predicate. The change does not leave inactive shared bytes uninitialized.

`proof.py` pins the exact source replacement and exercises 2,778,624 row/K/scale-vector combinations, including 947,466 masked out-of-allocation addresses, plus syntax/diff checks. Scoped pre-commit passes. This finite check accompanies the predicate proof; it is not exhaustive correctness or a replacement for the compiler/output gate. Planned GPU2 gate uses the existing unchanged eight-case public-wrapper replay helper, all four formats, 1/2 CTA, PDL off/on and changing/empty routes. Compare source-paired outputs and PTX/SASS to confirm preserved zero fill, removed selector, no spills or resource/geometry change. No performance claim yet.

The completed GPU2 gate (`../sf-source-address-gate/gate.json`) passed64 exact replays per source across32 GEMM and10 Prepare pairs, with unchanged registers/storage and no spills. Sixteen narrow-SFB kernels each lose one source selector; NOP alignment padding leaves encoded slot counts unchanged. Copy counts and zero-fill sizes0/4 are preserved. Wide/Prepare encodings are identical apart from one bounded descriptor-register permutation. The48-point fixed CAAC screen now uses task-local f718 source binding; the initial stale-HEAD preflight failed before any measurement and is preserved separately. Historical shared360 selections remain identical between runtime arms; this screen is not a fresh AUTO search.
