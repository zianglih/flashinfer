## Preparation and consumption contracts

- **Payload alignment and extent:** source/destination bases must be 32-byte aligned, rows have a byte length divisible by 32, and each participating thread copies eight `uint32` elements. Therefore the final vector cannot cross a valid row. SF bases and row widths are divisible by four bytes. These are enforced conditions, not merely compiler assumptions ([row-width checks](/Users/ziangli/playground/projects/flashinfer-w4a4-split-dynamic-n/flashinfer-regular-tma-review/flashinfer/fused_moe/cute_dsl/blackwell/moe_prepare.py:40); [valid-row copy](/Users/ziangli/playground/projects/flashinfer-w4a4-split-dynamic-n/flashinfer-regular-tma-review/flashinfer/fused_moe/cute_dsl/blackwell/moe_prepare.py:119); [base-alignment checks](/Users/ziangli/playground/projects/flashinfer-w4a4-split-dynamic-n/flashinfer-regular-tma-review/flashinfer/fused_moe/cute_dsl/blackwell/moe_prepare.py:244)). - **Valid-only payload and complete SF atoms:** routing metadata is read only for `row < count*route_tile`, and mapping is read only when that row is below its tile limit.
