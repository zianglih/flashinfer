The fixed-lane v2 scheduler adds compiler control flow; removing two PTX election sites did not remove two SASS elections or lower the static SASS count. All statements below describe the recorded artifacts, not measured execution cost.

For NVFP4 one-CTA FC1 with PDL (config0), the scheduler region grows from 74 to 103 static instructions, accounting for the complete kernel's +29 net increase. The old block is control SASS lines1975–2121 (PC0x3d80–0x4210); the new block is candidate lines1975–2179 (PC0x3d80–0x43e0), both under `evidence-v2/gate-v2-gpu6/`.

- The lane predicate appears at candidate line1975. The compiler surrounds the loop/conditional waits with seven ordinary BSSY/BSYNC pairs and one reconvergent pair: 16 additional synchronization-control instructions. The corresponding old scheduler has none. The outer lane split uses BSSY B3 at1977 and BSYNC B3 at2175; loop state uses BSSY B2 at1985 and BSYNC B2 at2163.
- The old query is one direct `UGETNEXTWORKID.BROADCAST` at control line2025. Candidate lines2047–2063 instead contain `VOTEU.ALL`, predicate conversion, a uniformly predicated query, `ELECT`, predicate maintenance, and `BRA.U.ANY` back to the query. This additional compiler sequence is visible even though the candidate PTX has a single raw try_cancel operation and fewer elect.sync sites. It is not evidence that query issue became cheaper.
- Metadata acquire waits are bracketed at candidate2003–2017; query-slot waits at2031–2037; response waits at2127–2133. Metadata publication is bracketed by the reconvergent pair2069/2117. These surround the existing waits/stores; tracked PTX mbarrier, shared fence, and UMMA site counts have not decreased.
- The old empty-barrier address uses uniform `UPRMT` values at1981/1985; the candidate materializes an address through a regular register (R11) at1991/1995 and uses it at2151. The whole-kernel resource record changes77→78 registers; no local-memory/stack spill occurs.

Both sources retain the same source-level `griddepcontrol_wait()` call outside their scheduling loop.
