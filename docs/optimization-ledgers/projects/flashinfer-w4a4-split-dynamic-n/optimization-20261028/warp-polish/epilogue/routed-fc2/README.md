# Routed FC2 scratch experiment

Independent clone `flashinfer-routed-fc2-review`, now based on retained `cb35c42f` (the same b45b control kernel), with all layout changes unstaged. `local-base-bump.json` proves all tracked working-file bytes were preserved. Remote gates/screens remain pinned to their original 99f4+combined+layout manifest. `layout-only.patch` is the experiment delta; `candidate.patch` includes the composed control. The experiment is complete and rejected; see RESULTS.md. No candidate was committed or pushed.

High-level unfused swap-AB always writes FC2 rows at the existing routed row index, then invokes the existing ordered combine with `input_is_expanded=False`. The private `output_is_routed` behavior defaults false, preserving low-level expanded/fused output contracts. `scatter_output=True` remains in force: bulk epilogue, scaling/rounding, prefetch and PDL policies are unchanged. Per-token scales continue indexing the same routed source row. The core wrapper sizes the output view to routing capacity, and this choice is in its compile key.

The shared combine gets an optional `match_row_extent=False` host policy argument. Only the swap-AB high-level caller enables it. This preserves the former expanded-layout geometry (including seven-vector H7168 prefill) while changing address layout; old permuted/W4A16 and non-swap callers retain their original selection. The combine kernel body itself is AST-identical.

The hypothesis is fewer FC2 output-address metadata loads and a compact touched virtual-address prefix, improving locality/TLB behavior. Live bytes are unchanged. Allocated capacity is worst-case tokens*top-k plus expert padding and can grow substantially at low token counts. If tokens*top-k <= local experts, capacity becomes tokens*top-k*route_tile, up to 16–256 times expanded scratch. For T4/top-k8/local32/N16/H7168 this is 512 versus 32 BF16 rows (7 MiB versus 0.44 MiB). Live bytes remain unchanged; allocation/graph footprint must be watched. This first screen retains current per-row bulk copies and SMEM layout. A contiguous 2D TMA store would be a separate follow-up requiring compatible SMEM swizzling.

Static checks: diff check and Python compilation pass; `audit_static.py` verifies byte-identical AST for the main kernel (including all barriers/PDL), combine kernel and FC1 launcher; 40,960 geometry comparisons preserve both old permuted behavior and new routed behavior versus former expanded tiling; 100 indexing cases check inverse mappings through N16–N256 padding, nonlocal/empty routes and top-k22. These do not replace GPU exactness or performance evidence.

`probe_pair.py` adapts the existing public source-pair gate. IDs0–10 retain all four formats, per-token scaling, static/CLC, PDL off/on, N16–256, one/two CTA, SiTU/Swiglu/Relu2, live/skew/empty/reactivated routing. IDs11–12 add T1025/H7168/top-k8 and T1025/H2048/top-k22. It asserts routed FC2 selection only in the candidate and captures combine geometry/codegen, requiring geometry equality across sources. Full output storage bytes are compared. Initial bounded IDs proposed: `0,1,2,3,11,12` (96 graph replays per source). `run_gate.py` retains source hashes, private source caches and idle-GPU checks. Do not launch before root releases a GPU.

Control source must be the frozen combined b45b source, not 99f4 alone. After exact/codegen gating, use existing frozen native winners and CUPTI cold-L2 full-chain timing; do not retune or rerun external baselines. Watch decode allocation/address cost and N3U top-k22 as well as V3 MX prefill. No new upstream tests, reference tests, sanitizer or tactic axis.

Read-only scheduler-agent review found no blocking layout/rounding/default-path issue and identified the decode allocation bound above. Gate r2 passed 96 candidate plus 96 control graph executions (96 cross-source comparisons); r1 control numerics passed but a helper-only combine capture assertion was corrected. The64-cell CAAC public screen against frozen b45b is complete: overall geometric change−0.292%. The standalone layout is rejected. Its owned local review clone was removed after verifying exactly the recorded four-file patch and no untracked files; source patch, manifests, helpers, raw codegen and all timing samples remain here.
