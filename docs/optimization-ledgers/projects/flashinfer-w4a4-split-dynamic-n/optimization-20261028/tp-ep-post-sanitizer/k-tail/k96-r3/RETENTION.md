# Retain R3: SM103 K96 capability and instruction cleanup

Decision: retain the general SM103 FP4 K96 path with descriptor reuse. Treat overall end-to-end performance as neutral; do not claim a broad speedup. No model/dimension heuristic, new tactic axis, public API control, or W4A16 change is introduced.

- Final local patch: `final-local.patch`, SHA256 `de9277e8db9133290921cfe3718af1e57f38317f52cb91520320d2f9152ea3a1`, based on `2cfb06afd4a6e180af37615dd5f1cea1fc188691`. All four files and scoped pre-commit results are bound by `final-local.json`; mypy and Ruff passed. Changes remain unstaged in the active review checkout; canonical and PR are untouched by this agent.
- Measured kernel: `9617d7da660d201a5e7c56bf33613cc24b1a20c05f8d1e022cd545c37efc31b5`, remote source receipt `d7f5d010436e5ef91f8ccda1cf8f7742353257cfd1bd30af84db834172fca854`. Host, kernel and test bytes match final local files. The final reference differs only by doc wrapping and explicit exactly-two-plan validation; producer independently verified arithmetic AST unchanged.
- Exactness: 68 numerical cases pass, including 12 cancellation discriminators and 56 geometry/CLC/PDL cases with cache-hit replays. Seven additional project-only descriptor-equality cases compare every emitted descriptor with the original SDK builder on GPU and traverse every ring slot. There are 110 ordinary and 13 instrumented owned compilations. These checks preserve zero tolerance and the actual per-stage native update plan; they do not assert K96 is numerically identical to K64.
- Code generation: all gate kernels have zero local-memory/stack usage and 1024B shared alignment. Uniform-register spill/fill sites are counted separately. R3 removes instructions in five of six captured winner kernels versus R2; the other increases by 16 instructions and two spill/fill pairs but remains below K64 in both counts. `codegen-summary.json` records all three versions. Descriptor probing is excluded from production codegen and timing.
- Capacity: all 64 measured cells / 128 FC bindings preserve the winning tactic, operand-stage count and epilogue scratch size. The alignment change is included in the compile-time capacity planner. No forced tactic became inadmissible, and no retuning occurred.
- Performance: 64 cells, 256 medians, 25,600 CUPTI samples; same frozen winners, C-A-A-C, 10 warmups, 100 samples per phase, cold L2. Overall +0.139%, decode −0.066%, prefill +0.345%; worst row −0.402%. Stable modest EP16K signals include V3 W4A4 +1.606%, V3 per-token +0.903%, and N3U W4A4 +0.949%. K3 EP16K +3.498% is unstable and is not used as a claimed benefit. Standard full-sample medians remain primary; temporal strata are diagnostic only.
- Evidence: 467 performance files and 516 gate files fetched and hash-verified. `perf-summary.json`, `strata-summary.json`, `capacity-summary.json`, `GATE.md`, and `PERFORMANCE.md` provide raw bindings and full breakdowns. External baseline data and published matrix cells were not replaced by this screen.
- Validation boundary: this is not a K96 Compute Sanitizer run. Prior 150-case sanitizer evidence remains scoped to its original d1767 source. No additional K768 or wider-stage experiment was run. Both devboxes and persistent native compilation caches are retained; the three assigned GPUs are idle.
