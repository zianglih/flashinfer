# Independent review of logical-stage-K handoff

No source blocker found in the source hashes recorded in `independent-source-review.json`. This audit does not replace the paired GPU exact/codegen gates.

- Both mainloops pass only the logical full/tail stage extent. The peeled section remains compile-time, the acquired stage still has exactly one wait/release sequence, and no new runtime atom predicate, tactic, kernel argument or public API is introduced.
- Blockscaled CTA group derives from the same `tiled_mma.thr_id.shape` used when constructing its cluster layout. The emitter's M/N instruction descriptor, activation shift, SF publication and TMEM geometry are untouched. Ordinary descriptor fragments are made by this same MMA object; its native K therefore supplies the former fragment-derived atom extent.
- K96 deliberately still uses the SDK's K64 partition atom. The emitter first rounds logical `stage_k` up to native K, then constructs the mixed 96/64 sequence. It does not decompose the unrounded logical tail. An independent AST-extracted comparison of the old/new width expressions passes 6,144 plans spanning logical K1–2048 for native K32, K64 and K96-on-K64. This includes hypothetical partial-native-atom tails, beyond current host admission, and preserves per-stage reset/update ordering.
- W4A16 obtains M/N/K from the existing trivial MMA created with `self.mma_tiler[:2]`. Dynamic-N admission already requires 128 accumulator rows per CTA; therefore its physical instruction M remains128/256 for one/two CTAs. Single M/N-atom checks remain, including N192, so taking M/N from `shape_mnk` does not switch to a logical multi-atom tiler. The exact/codegen gate must explicitly cover N192 and both CTA groups to verify the actual SDK representation.
- W4A16 native K is explicitly checked as16. The emitter bounds the live logical extent by fragment capacity, verifies equal A/B K capacities and keeps the single M/N atom constraints. The caller formerly supplied n_alignment8/16; deriving8×CTA-group preserves those values. There are no other calls to this private emitter in the repository; the similarly named MegaMoE emitter is a separate unchanged function.
- The static W4A16 path derives the atom count locally at the MMA emission boundary. Full-loop `unroll=1`, accumulation initialization, per-stage waits/releases and the ready-peek state are unchanged. The packed FC2 change is outside this handoff and remains separately measured/qualified.

Acceptance boundary: require unchanged paired PTX/SASS/resources for the handoff itself across ordinary K32/K64, mixedK96/K64, partial/full stages, both CTA groups, both channel-tile counts, W4 N192 and nominal-N256 narrow tails. If identity holds, the already-finished performance screens remain valid for the corresponding measured computation; the final table refresh still binds to the eventual clean retained head.
