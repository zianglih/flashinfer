# Independent combined FC2 / K96 review

Source-bound to `source.json`, base `21fbe72c`. Read-only; no GPU claims.

- **Admission and capacity:** the host and kernel share exactly one bulk-output eligibility predicate. AST-extracted planner audit covers 1,350 combinations (1,260 admitted; 90 rejected), including 128/1024-byte operand alignment, FP4/FP8 and SF16/SF32, M128/256/512, routed N16–256, auto/4/8 K steps, CLC on/off and BF16/FP16/FP32 outputs. For every admitted public `num_stages=None` configuration, compact eligibility implies a realized bulk slab. An independent aligned SharedStorage extent model fits both the planner reservation and 232,448-byte SMEM limit. Full TMA slabs use 128 elements per row inside the unchanged 136-element reservation. Explicit forced-depth diagnostics are outside this admission proof.
- **K96 composition:** constructor, capability dispatch, 1024-byte alignment, actual-layout byte assertion, stage selection, and per-tile SFB stride remain intact. The output descriptor uses separate epilogue scratch; it neither changes operand offsets nor consumes extra SMEM/TMEM. No new tactic axis is introduced.
- **Metadata dependencies:** prepare writes a prefix over only valid routed rows. FC2 epilogue warps perform the existing grid dependency wait before reading that prefix. Exactly the first channel tile/CTA publishes each expanded-to-compact index; finalization reads it only after its FC2 grid wait and only for local valid routes. Early FC1/FC2 publication therefore cannot expose partially written new metadata.
- **Store lifetime and bounds:** complete slabs stay within a tile's compact interval; partial slabs preserve the existing masked per-row copy. The 128B-swizzled two-half-row store uses an absolute-byte swizzle, including 32-row slab phases. Existing proxy fence plus 128-thread barrier orders producers before TMA; issuing-thread bulk waits plus the same barrier protect reuse. TMEM release remains after all relevant TMEM reads, independent of subsequent shared/global transfer completion.
- **Compatibility:** high-level unfused swap-AB alone opts into compact output. Low-level expanded/fused defaults, legacy/Rubin selection, W4A16, rounding order and per-token scale behavior remain unchanged in this diff. New cache keys include pointer presence/layout specialization.

No blocking source or planner finding. Combined exact/codegen, actual 32-row slab coverage and performance remain the owning agent's runtime gates; this review does not substitute for them.
